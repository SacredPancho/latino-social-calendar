Privacy Policy

Last updated: July 31, 2026

Latino Social Calendar is a personal, single-owner content-planning tool built for the Mexillicious social media channels. It is not a public product, has no public sign-up, and is used by a single owner/operator only.

What data this tool accesses

This tool uses the YouTube Data API to upload video files, titles, descriptions, tags, and privacy settings to the owner's own YouTube channel (the Mexillicious Brand Account). It may also use image/video generation services (such as Krea) to create visual assets from story ideas researched by the owner.

How data is used

Data accessed via the YouTube Data API is used solely to publish video content to the owner's own channel, at the owner's direction. No data is sold, shared with third parties, or used for advertising.

Data storage

Content plans, drafts, and credentials are stored locally on the owner's own computer and in the owner's private cloud storage. OAuth tokens are stored locally and used only to authenticate the owner's own requests to Google's APIs.

Data retention and deletion

The owner may revoke this application's access at any time via Google Account permissions. Deleting the local token file removes all locally cached credentials.

Contact

Questions about this policy can be sent to sacredpixel@gmail.com.
